# KDP Production Guide

Use this file when the user asks for publication readiness, upload preparation, quality review, or a complete production pipeline.

## Recommended Intake

Collect only what is needed for the task:

- Age range
- Book language
- Theme and lesson
- Main character
- Page count
- Trim size
- Interior type: color or black and white
- Art style
- Layout tool
- Whether the user wants prompts, finished content, or a review

## Children's Book Quality Heuristics

- For ages 3-5, use concrete emotions, very simple stakes, repetition, and fewer words per page.
- For ages 4-8, use a clear problem, visible character growth, and 20-60 words per page.
- For ages 6-9, allow more complex scenes, humor, and slightly longer sentences.
- Each page should create an imageable moment.
- A lesson works best when the main character earns it through a choice.
- Avoid moral lectures at the end unless the user specifically wants an explicit moral.
- Parent-facing value should be clear: sleep routine, confidence, kindness, emotional regulation, school readiness, manners, resilience, curiosity, or family bonding.

## Illustration Consistency Rules

Every page illustration prompt should repeat:

- Character name
- Species/type and age
- Key physical traits
- Outfit or accessory
- Color palette
- Broad art style
- Mood and facial expression
- Setting continuity

Avoid:

- "In the style of [living artist]"
- Protected character or brand references
- Text embedded in images unless the user needs a cover mockup
- Vague prompts such as "make it cute" without visual anchors

## KDP Listing Checks

Good KDP descriptions should:

- Start with a parent-relevant hook
- Explain the emotional and educational benefit
- Mention the child age range naturally
- Include relevant keywords without stuffing
- Make the book sound specific, not generic
- End with a gentle purchase cue

Weak descriptions usually:

- Only summarize the plot
- Overpromise educational outcomes
- Use too many keywords
- Ignore the parent buyer
- Sound like a generic AI blurb

## Print Readiness Checks

Check these before suggesting upload:

- Trim size is selected and consistent across interior and cover.
- Page count is even where the layout requires spreads.
- Text stays inside the safe area.
- Full-page art includes bleed if it reaches page edges.
- No important faces, text, or details are near trim edges.
- Cover has front, back, and spine requirements handled.
- PDF is exported for print, not screen preview.
- Images are high enough quality for the chosen trim size.
- Black text is readable over illustrations.

## Risk Language

Use careful wording:

- "Potential risk" instead of "infringement"
- "May resemble" instead of "copies"
- "Consider human legal review before publishing" for medium or high risk
- "I cannot verify Amazon's current category availability from local context" when not browsing

When current KDP rules, categories, or upload requirements matter, verify with current Amazon KDP documentation if the user asks for current publishing accuracy.
